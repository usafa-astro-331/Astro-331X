# Astro 331X

In this class we will use Arduinos to build a satellite analog called FlatSAT to explore spacecraft design lessons. FlatSAT is a mini version of the FalconSAT Avionics Test Bed (ATB). 

<img src="sources/fritzing/331X_bb.svg" alt="breadboard"  />


## Software
You will need to install Arduino IDE: https://www.arduino.cc/en/software/
You may want to install Obsidian (optional): https://obsidian.md/

## Course content
Course material is available from https://github.com/usafa-astro-331/Astro-331X/releases
Select the latest release and download the zip file.
